Auth0 → JWT → Conduit → MCP session → tool call

Public capability

conduit:read provides workspace and GitHub operations.

Admin capability

conduit:admin is required by the Auth0 Management API tools.

Credential isolation

The server-side Auth0 Management API secret is never delegated to callers.

Security is part of the design.

The global OAuth gate authenticates the caller; per-tool authorization determines whether that caller can cross a sensitive capability boundary.

Caller authentication

OAuth 2.1RS256JWKSissueraudience

JWT signature, issuer, audience, timing, key ID, and required scopes are validated.

cd conduit-mcp
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
conduit --transport stdio

conduit --transport http --port 8000
