Built around real engineering concerns.

OAuth resource server

JWT verification against JWKS with issuer, audience, timing, key ID, and scope checks.

Sandboxed workspace

Path traversal and absolute-path escapes are blocked before filesystem access.

GitHub intelligence

Live repository metadata, search, profiles, and composed research workflows.

Resumable sessions

HTTP streams use a bounded event store for replay after reconnects.

Explicit threat model

Prompt injection and resource limits are documented as real limitations.

Reproducible benchmarks

Transport and authentication overhead is measured rather than guessed.

Security is part of the design.

Authentication proves who called Conduit; it does not make external content or deployment credentials trustworthy to the caller.

Run it locally.

git clone https://github.com/devXyi/conduit-mcp.git
cd conduit-mcp
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

# Local MCP
conduit --transport stdio

# HTTP
conduit --transport http --port 8000
