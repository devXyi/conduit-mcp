A serious MCP server.

Conduit gives AI agents a sandboxed local workspace and live GitHub lookups over stdio and Streamable HTTP — with OAuth 2.1 resource-server authentication, session resumability, security boundaries, and server-side tool composition.

Built around real engineering concerns.

Conduit treats MCP as a systems problem: trust boundaries, authentication, failure modes, protocol behavior, and measurable performance.

OAuth 2.1 resource server

Bearer-token verification against an external Authorization Server's JWKS, with issuer, audience, expiry, and signature validation.

Session resumability

HTTP streams use a bounded event store so reconnecting clients can replay events they missed.

Server-side composition

research_repo orchestrates multiple operations concurrently and isolates partial failures.

Sandboxed filesystem

Workspace paths are resolved and checked before filesystem access, blocking traversal and absolute-path escapes.

Untrusted-content boundaries

Tool output is treated as data rather than instructions, with the threat-model limitations explicitly documented.

Real integration tests

Tests exercise real MCP subprocesses, HTTP sockets, JWTs, JWKS endpoints, OAuth rejection paths, and key rotation.

Security is part of the design.

Conduit distinguishes between protecting the caller and protecting the agent from untrusted content flowing through a legitimate tool call.

Authentication

OAuth 2.1RS256JWKSRFC 8707 audienceexp / nbfissuer validation

Conduit never issues credentials. A configured external Authorization Server supplies tokens; Conduit verifies them on the MCP HTTP path.

Threat model

Path traversalConfused deputyPrompt injectionResource exhaustion

The project documents what is mitigated, what is only partially mitigated, and what is deliberately outside the shipped attack surface.

Run it locally.

Conduit is designed to work with local MCP clients or as a network-reachable Streamable HTTP server.

git clone https://github.com/devXyi/conduit-mcp.git
cd conduit-mcp
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

# Local MCP client
conduit --transport stdio

# Network transport
conduit --transport http --port 8000
